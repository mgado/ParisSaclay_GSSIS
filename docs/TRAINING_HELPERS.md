# API origins and training helpers

The **Origin** column in every exercise and solution cheat sheet identifies
where each API comes from. MATLAB is required throughout the course.

| Origin label | Meaning |
|---|---|
| A MathWorks product, such as MATLAB or Simulink | Shipped product functionality; it is not an exercise-specific wrapper |
| A library or support package | A MathWorks add-on; install the compatible R2026b package and its parent product |
| Training helper | A provided `.m` function for this training; its source is linked so you can inspect the MathWorks APIs it uses |
| MathWorks example data | A shipped example utility or dataset helper, rather than a general application API |
| Generated interface | A MEX/SIL/PIL entry generated by the build; it is available after that build succeeds |
| Workflow reference | Documentation explaining a process; it is not a callable function |

The column identifies API ownership and relevant dependencies. The README's
[requirements tables](../README.md#requirements) list the complete products,
compiler, support packages and hardware setup needed for each exercise.
For example, a MATLAB API may operate on an object supplied by another toolbox.

## Provided helper functions

These functions are **training helpers**, not installed MATLAB/toolbox APIs.
Open their linked source to see their inputs, assumptions and implementation.
MATLAB is implicit in every dependency list.

| Helper | Purpose | Products used by the helper |
|---|---|---|
| [requireTrainingProject](../src/requireTrainingProject.m) | Require and locate the opened training Project | MATLAB |
| [setup_check](../setup_check.m) | Report installed training capabilities | MATLAB |
| [socEstimate](../src/socEstimate.m) | Evaluate the analytic SOC reference | MATLAB |
| [makeBatteryData](../src/makeBatteryData.m) | Create the reproducible fictive sensor dataset | MATLAB |
| [trainSOCNetwork](../src/trainSOCNetwork.m) | Train the compact neural SOC reference | Deep Learning Toolbox |
| [ensureSOCModel](../src/ensureSOCModel.m) | Export or reuse the provided neural model | Simulink; Deep Learning Toolbox |
| [makeInspectionImages](../src/makeInspectionImages.m) | Create illustrative inspection datasets | MATLAB |
| [coolingPINNLoss](../src/coolingPINNLoss.m) | Define the cooling PINN's physics/data loss | Deep Learning Toolbox |
| [predictPiSOC](../src/predictPiSOC.m) | Load and execute the supplied neural compiler entry point | MATLAB Coder; Deep Learning Toolbox |
| [simulateBatterySystem](../src/simulateBatterySystem.m) | Configure the coupled battery scenario and compute its test observations | Simulink; Deep Learning Toolbox; compiler for model-reference simulation |
| [cocoSmallYOLO](../src/cocoSmallYOLO.m) | Provide the supplied detector compiler entry point | MATLAB Coder; Computer Vision Toolbox; Deep Learning Toolbox; GPU Coder for CUDA builds |
| [invokeSOCModel](../src/invokeSOCModel.m) | Provide the exported-program compiler entry point | MATLAB Coder; PyTorch/LiteRT support package |
| [packageTraining](../src/packageTraining.m) | Package the provided project files | MATLAB |
| [openExercise](../openExercise.m) | Open a workshop or solution from the catalog | MATLAB |
| [runExercise](../runExercise.m) | Execute a selected exercise in its own workspace | MATLAB, plus the selected exercise's products |
| [demoAgenda](../demoAgenda.m) | Display the exercise catalog | MATLAB |

For example, `dlfeval` is a Deep Learning Toolbox API, while the
`coolingPINNLoss` callback passed to it is a training helper. Likewise,
`Simulink.SimulationInput` and `sim` are Simulink APIs, while
`simulateBatterySystem` combines them into this training's scenario workflow.

## Library and support-package names

The cheat sheets use compact labels for these MathWorks add-ons:

| Cheat-sheet label | Package to install |
|---|---|
| AI Verification Library | AI Verification Library for Deep Learning Toolbox |
| Model Compression Library | Deep Learning Toolbox Model Compression Library |
| PyTorch converter | Deep Learning Toolbox Converter for PyTorch Model Format |
| PyTorch/LiteRT support package | MATLAB Coder Support Package for PyTorch and LiteRT Models |
| MATLAB Coder NVIDIA support package | MATLAB Coder Support Package for NVIDIA Jetson and NVIDIA DRIVE Platforms |
| Raspberry Pi Blockset | Raspberry Pi Blockset |

Target `webcam`/`snapshot` belong to NVIDIA support. The host
`videoinput`/`getsnapshot` route uses Image Acquisition Toolbox. In R2026b,
the host `imresize` used in this course is a MATLAB API; `imageshow` belongs
to Image Processing Toolbox. `digitTrain4DArrayData` and
`digitTest4DArrayData` are shipped Deep Learning Toolbox example helpers.

Inspect installed products with `ver`, add-ons with
`matlab.addons.installedAddons`, and a function's location with `which`.
Use the linked documentation to check the exact overload and release.
